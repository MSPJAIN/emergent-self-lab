# Sponsorship and support

Emergent Self Lab is an independent attempt to study whether durable, identity-like behavior can emerge in an artificial system from irreversible experience.

This work is still exploratory. Support may eventually help make it possible to run experiments and explain them clearly, but it does not purchase a result.

## Current payment status

GitHub Sponsors' signup flow allows Taiwan as a residence choice, but its direct bank-payout step currently reports that Taiwan is not supported. This project is therefore using an external PayPal.Me route instead of presenting a direct GitHub Sponsors payout as available.

The active route is [PayPal.Me/MSPJIAN](https://paypal.me/MSPJIAN) for international, one-time support. The receiving method has been checked for:

- Taiwan residence and bank-account eligibility;
- identity and tax verification;
- withdrawal and currency-conversion rules;
- refund handling and transaction records;
- whether the service permits this type of independent research support.

The setup checklist is in [`docs/support/paypal-taiwan-setup.md`](docs/support/paypal-taiwan-setup.md).

This is a temporary transparency decision, not a claim that every external platform has the same restriction.

## What support helps with

Funds may be used for:

- model and API usage;
- local compute, storage, and backups;
- evaluation runs and replication attempts;
- documentation, diagrams, and public release work;
- time spent maintaining the repository and responding to serious technical criticism.

The exact split will change as the work changes. When practical, major spending categories and experiment milestones will be summarized publicly.

## What sponsors should not expect

Sponsorship does not provide:

- investment ownership or a financial return;
- a guaranteed discovery, product, or publication;
- control over the scientific conclusion;
- private access to personal data or credentials;
- ownership of the project's core intellectual property;
- a claim that an agent is conscious because it speaks as if it is.

Supporters can help the work happen. They cannot buy the answer.

## Transparency promise

I will make a good-faith effort to distinguish among:

1. what the system did;
2. what the measurements show;
3. what I think those measurements might mean;
4. what remains unknown.

Negative results, failed runs, and protocol changes are part of the record. If a result depends on a hidden implementation detail, that limitation will be stated rather than disguised as full reproducibility.

## Public work and private IP

The repository is the open research layer, not a complete publication of every implementation detail. The core identity engine, proprietary algorithms, private infrastructure, credentials, and sensitive data may remain private.

This boundary protects the project's ability to continue. It does not create a license to make unsupported claims. Public conclusions must stay within the evidence that can actually be shown.

## Suggested small-support levels

These are planning levels for a future support channel, not active payment tiers or promises of benefits. The first PayPal.Me route is intended for one-time support; recurring tiers require a separate verification step:

- **$3/month — Curious observer:** helps cover a small part of ongoing usage and storage.
- **$10/month — Experiment supporter:** helps fund evaluation runs and public write-ups.
- **$25/month — Replication supporter:** helps make room for repeated runs, controls, and failure analysis.
- **$75/month or more — Sustaining supporter:** helps keep the project moving through longer experiments and maintenance.

All supporters receive the same basic commitment: honest reporting, clear boundaries, and no manufactured certainty.
